# Folsk organization profile

- [`profile/README.md`](profile/README.md) — GitHub organization profile.
- [`profile/assets/avatar.png`](profile/assets/avatar.png) — 1024 × 1024 profile picture.
- [`profile/assets/banner.png`](profile/assets/banner.png) — 1800 × 600 README banner.
- Matching SVG files preserve editable vector artwork.

The artwork uses the existing selected white heart and lowercase wordmark from `folsk/assets`, with the cobalt, white, and yellow brand palette. The avatar comes from the existing app-icon vector; the banner extends the existing lockup without redrawing the identity. Source reference and provenance remain in the assets repository.

The organization avatar must be uploaded separately in GitHub organization settings.
